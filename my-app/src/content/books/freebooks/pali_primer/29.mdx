<Divider />

**Aµµhi = bone, seed**

|      | Singular                     | Plural              |
| ---- | ---------------------------- | ------------------- |
| Nom. | aµµhi                        | aµµhī, aµµhīni      |
| Voc. | aµµhi                        | aµµhī, aµµhīni      |
| Acc. | aµµhiṃ                       | aµµhī, aµµhīni      |
| Ins. | aµµhinā                      | aµµhīhi, (aµµhībhi) |
| Abl. | aµµhinā                      | aµµhīhi, (aµµhībhi) |
| Dat. | aµµhino, aµµhissa            | aµµhīnaṃ            |
| Gen. | aµµhino, aµµhissa            | aµµhīnaṃ            |
| Loc. | aµµhini, aµµhimhi, aµµhismiṃ | aµµhīsu             |

N.B. This declension is similar to the aggi declension except in the nominative, vocative and accusative cases.
